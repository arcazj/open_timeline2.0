# Legacy Hazard Assets

These eight PNG files are byte-for-byte copies of the named files under
`C:/projects/openbexi_timeline/icon`. The repository's supplied license is retained
in `LEGACY-LICENSE.txt` and embedded in the standalone notices. No external image
URLs are loaded. The source repository does not provide separate per-image
attribution; release provenance review remains open.

Only the identifiers in `shared/legacy-hazard-icons.json` can select these images.
They retain their original colors without applying the record's color as a tint.
The main band uses a fixed 16 by 16 pixel footprint at the event timestamp.
The overview remains a compact, color-coded summary rather than loading images.
